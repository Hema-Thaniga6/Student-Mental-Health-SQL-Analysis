# Student Mental Health Analysis Using SQL

## Project Overview

This project investigates whether the length of stay in a foreign country impacts the mental health of international students.

Using SQL, I analyzed survey data collected from students attending an international university in Japan.

---

## Objective

To determine how the duration of stay abroad affects:

- Depression levels
- Social connectedness
- Acculturative stress

---

## Dataset

The dataset contains information about:

- International students
- Length of stay
- Depression scores (PHQ)
- Social connectedness scores (SCS)
- Acculturative stress scores (AS)

---

## Tools Used

- SQL
- PostgreSQL
- DataCamp

---

## SQL Concepts Demonstrated

- WHERE
- GROUP BY
- COUNT()
- AVG()
- ORDER BY
- Aliasing

---

## SQL Query

The analysis grouped international students by length of stay and calculated:

- Number of students
- Average depression scores
- Average social connectedness scores
- Average acculturative stress scores

---

## Key Findings

- Mental health indicators varied according to students' length of stay.
- Depression and stress levels showed differences between stay groups.
- Length of stay appears to be an important factor when studying international student wellbeing.
